# Toluwa Stephen Adebayo — Portfolio

Professional portfolio covering IT operations, technical support, infrastructure and endpoint security.

## Contents

- Career history, education and capabilities
- Six career case studies
- Six clearly labelled demonstration work samples
- Downloadable CV and complete portfolio PDF

## Hosting

This is a static site. GitHub Pages should publish the `main` branch from `/ (root)`.
The `.nojekyll` file disables Jekyll processing. All asset links are relative so the site works under the repository URL.

## Updating

Edit `index.html`, `style.css`, or the pages in `samples/`. Downloadable PDFs are in `downloads/`.
Demonstration samples use synthetic scenarios and are not client deliverables.
